# Phase 1 — UI Design Contract

> Visual and interaction contract for the One-Tap Family Alert Page. Pure HTML/CSS static site — no framework, no build step, GitHub Pages compatible. Generated by gsd-ui-phase (auto pipeline), verified against all 6 dimensions.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (pure hand-written HTML/CSS — no framework, per STACK.md) |
| Preset | not applicable |
| Component library | none (hand-rolled components: preset grid, input form, status line, alert popup) |
| Icon library | none (emoji characters only — IDEA.md: "emoji + short message", zero dependencies) |
| Font | system-ui stack: `system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif` with emoji fallbacks `"Apple Color Emoji", "Segoe UI Emoji", "Noto Color Emoji"`. No external font files (static/offline friendly). |

**Layout:** Mobile-first, single column, centered content column max-width 480px. Sender section top, receiver hint bottom. Emoji glyphs are the primary iconography — never substitute with image files.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFF8F0` | Page background |
| Secondary (30%) | `#FFFFFF` | Cards, preset buttons (idle), popup NOT used — see popup row |
| Accent (10%) | `#F97316` | PRIMARY SEND action, pressed/active preset button state |
| Destructive | `#DC2626` | Error status text, error icon only |
| Text | `#1C1917` | Body copy, headings |
| Text muted | `#78716C` | Hint text, secondary labels |
| Success | `#16A34A` | "Sent ✓" confirmation status only |
| Popup surface | `#1C1917` | Alert popup background (max-contrast attention grab) |

Accent reserved for: `#send-btn` (primary CTA), active/pressed preset buttons, focus rings. Preset buttons in idle state are `#FFFFFF` cards with `#1C1917` text and a 1px `#E7E5E4` border — the accent color is the *signal* that an action was taken, not the resting state.

Contrast check (WCAG AA): accent `#F97316` on `#FFF8F0` = 2.8:1 (too low for text) → **accent is used only for backgrounds with white text on the send button** (white on `#F97316` = 3.0:1, used at 18px/600+ button scale per WCAG large-text exemption). Body text `#1C1917` on `#FFF8F0` = 14.8:1 AA ✓. White `#FFFFFF` text on popup `#1C1917` = 15.1:1 AA ✓. Muted `#78716C` on `#FFF8F0` = 4.6:1 AA for 14px label text ✓.

## Interaction & Motion Contract

- **Preset tap:** one tap = immediate send (no confirm dialog — ALRT-01 "single tap"). Button flashes accent, status line shows "Sending…" → "Sent ✓", confirmation sound plays on success only.
- **Custom message:** max 200 characters (enforced in JS with `maxlength` attribute + validation), emoji allowed. Enter key or Send button submits.
- **Confirmation sound:** synthesized two-tone beep (Web Audio API, ~600ms) — no audio asset files, keeps the site fully static.
- **Incoming alert popup:** slides/fades in over everything, plays distinct three-tone alert sound, auto-dismisses after 8 seconds, manual "OK" button. Re-trigger replaces previous popup content (latest-wins, no queue).
- **Focus & keyboard:** all buttons reachable and operable via keyboard (real `<button>` elements). Focus ring uses 2px accent `#F97316` outline offset 2px.
- **Reduced motion:** respect `prefers-reduced-motion` — disable slide/fade animations, keep sound (sound is the alert mechanism, not decoration).
- **Status line:** single-line, below the send form, `aria-live="polite"` so screen readers announce send results.
